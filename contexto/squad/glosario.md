# Glosario del Dominio

> Vocabulario clave del dominio del producto y el equipo.
> Referencia transversal para todos los documentos del repositorio.
> Agregar términos conforme el equipo los use en sesiones y documentos.

---

| Término | Definición en contexto |
|---------|----------------------|
| _[Término del dominio]_ | _Definición específica para este producto/contexto_ |
| Squad | Equipo multidisciplinario de producto compuesto por PM, Designer y Engineer |
| Tríada | Los tres roles core del squad: Product Manager, Product Designer, Product Engineer |
| SDD | Spec-Driven Development — paradigma donde todo lo que se construye primero se especifica |
| OST | Opportunity Solution Tree — árbol que conecta el outcome de negocio con oportunidades y soluciones |
| Shape | Sub-proceso 1: descubrir y priorizar oportunidades |
| Ideate & Validate | Sub-proceso 2: idear soluciones y validar supuestos |
| Handoff to Delivery | Sub-proceso 3: convertir la solución elegida en specs para el equipo de desarrollo |
| PBI | Product Backlog Item — unidad de trabajo del backlog |
| PRD | Product Requirements Document — spec detallada de un feature |
| JTBD | Jobs To Be Done — el trabajo que el usuario busca hacer con el producto |
