# Índice de Contexto — Shape

Al iniciar una sesión de Shape, leer los siguientes archivos **en este orden**:

1. `contexto/corporativo/estrategia-producto.md`
2. `contexto/squad/squad.md`
3. `contexto/estrategia/ost.md` — leer solo hasta nivel de Opportunities
4. `contexto/estrategia/evidencia-validada.md`
5. `contexto/estrategia/roadmap-discovery-shape.md`
6. `shape/entrevistas/snapshots/` — snapshots más recientes disponibles (si existen)
7. `shape/experience-map.md` — si existe

## No leer por defecto

- `shape/_historia/` — solo si el usuario lo indica explícitamente
- `contexto/extendido/` — solo cuando una regla de sub-proceso lo requiera
- `legacy/` — solo como referencia histórica si el usuario lo solicita
